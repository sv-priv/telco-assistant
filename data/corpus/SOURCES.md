**Modifications.** HTML converted to structured text and segmented into
article-level chunks with metadata for retrieval. Text content unaltered.

**Why the repealed regulation is included.** 531/2012 is retained deliberately so
the system must distinguish current law from superseded law via the `status` and
`effective_date` metadata. Answering from it is a failure mode the eval tests for.

## Layer 3 — Operator documents (synthetic)

All files under `corpus/operator/` are **synthetic**. They are generated by
`data/generate_corpus.py` from the canonical catalogue in `data/catalog.py`.

The operator "Вардар Мобиле / Vardar Mobile" **does not exist**. Document
structure is modelled on the general shape of published Macedonian operator
terms, but no text is copied from any operator. All prices, point values and
promotional terms are invented.

Device specifications are approximate manufacturer figures included for realism;
all pricing attached to them is synthetic.

## Customer data

All customer, subscription, usage, travel and billing data is generated. **No
real personal data appears anywhere in this repository, by design.** There is no
acceptable source of real customer records for a project of this kind.
