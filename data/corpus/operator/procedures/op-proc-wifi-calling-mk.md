# Активација на Wi-Fi Calling

| Поле | Вредност |
|---|---|
| Наплата дома | како вообичаен домашен повик |
| Наплата во странство преку Wi-Fi | по домашна тарифа, не по роаминг тарифа |
| Итни повици | користат адреса регистрирана во Мој Вардар, ажурирајте ја при преселба |

Ако постапката не успее, јавете се на 1300 со моделот на уредот и верзијата на оперативниот систем.
