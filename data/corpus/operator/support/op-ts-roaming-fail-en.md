# Roaming not working abroad

## Resolution steps

1. Check that roaming is enabled on the account with `*123#`.
2. Check that data roaming is enabled in device settings. These are two separate permissions and both must be on.
3. Check whether the monthly cap of 3.000 MKD has been reached. If so, send ROAMING OK to 1300.
4. Try manual network selection. Some foreign networks have no agreement with the operator.
5. New subscribers require a deposit for roaming during the first three months.

## If none of the steps help

Call 1300 or open a request in My Vardar. State the device model, the exact time the problem started, and whether it happens in one location or everywhere.
