# Slow mobile internet

## Resolution steps

1. Test outdoors rather than indoors behind thick walls.
2. Compare at different times. The network is busiest between 19:00 and 23:00.
3. Check whether the allowance is exhausted. After that, speed is 64 kbps.
4. Check whether the device is on 4G or 5G. Locking to 3G gives materially lower speeds.
5. Check for an active VPN. A VPN reduces throughput by 10 to 40%.
6. If speed is below 25% of the contracted rate for more than 3 days, file a complaint.

## If none of the steps help

Call 1300 or open a request in My Vardar. State the device model, the exact time the problem started, and whether it happens in one location or everywhere.
