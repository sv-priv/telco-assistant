# Mobile data not working

## Resolution steps

1. Check that mobile data is on and data saver is off.
2. Check your remaining allowance with `*123#`.
3. Check APN settings.
4. If abroad, check that data roaming is enabled in device settings. This is separate from the operator-side permission.
5. Reset network settings. This clears saved Wi-Fi passwords.

## If none of the steps help

Call 1300 or open a request in My Vardar. State the device model, the exact time the problem started, and whether it happens in one location or everywhere.
