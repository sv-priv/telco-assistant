# Cannot send SMS

## Resolution steps

1. Check the message centre number. For Vardar Mobile it is +389 70 100 100.
2. If you have used another operator's SIM in this device, that number may have persisted. This is the most common cause.
3. Check free memory on SIM and device.
4. Short codes and premium services are not included in the allowance.

## If none of the steps help

Call 1300 or open a request in My Vardar. State the device model, the exact time the problem started, and whether it happens in one location or everywhere.
